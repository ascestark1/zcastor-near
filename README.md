# Zcastor (baseline)

This commit is the baseline: the Zcastor execution engine as it existed before
NEAR HACKATHON's window opened on 19 October 2026. It is tagged `pre-hackathon`
and is not offered for judging. The tuned policy and the signal generator are
private; `config/policy.json` is a demo with placeholder numbers, and tests that
pin the private numbers are left out.

The hackathon work is the diff from this tag to `hackathon-submission`.
